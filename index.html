Guía rápida

El alfabeto español y las ideas detrás de cada operación.

Alfabeto: cada carácter tiene un valor

A cada letra le corresponde un entero del 1 al 27. La Ñ cuenta como una letra y el espacio en blanco vale exactamente 0. Los acentos se normalizan automáticamente.

Una clave reversible

La matriz cuadrada A debe contener enteros y tener determinante distinto de cero. Así existe su inversa A⁻¹.

Codificación y recuperación

El mensaje ocupa exactamente n² posiciones. Si es más corto, las posiciones restantes se completan con ceros. Se calcula B = A × X y, para recuperar el texto, X = A⁻¹ × B.

Nota: es un modelo educativo sin aritmética modular, no un método criptográfico seguro.
